# Changelog

## [0.1.0] — 2026-05-28

### Added
- `VoxEngine` with gTTS (online) and pyttsx3 (offline) backends
- File reader for `.txt`, `.pdf`, and `.docx` formats
- Click CLI with `speak` and `read` commands
- Flask REST API with `/speak`, `/read`, `/health`, `/output` endpoints
- TypeScript CLI wrapper with typed API client
- Long document chunking for large files
